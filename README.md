# 2026년 청소년상담사 1급 실전 모의고사 모바일 CBT 웹앱

2026년도 제25회 청소년상담사 1급 국가자격시험 대비 실전 모의고사 1교시(75문항) 및 2교시(100문항) 총 175문항의 모바일 최적화 CBT 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 화면 구성

### 1. 📱 1화면 1문제 (모바일 터치 최적화)
- 한 번에 한 문제씩 집중해서 풀 수 있는 카드 뷰 레이아웃
- 직관적인 **원형 체크박스 / 라디오 버튼 (①, ②, ③, ④, ⑤)** 선택지
- 표, 긴 지문, 사례 박스 상하 부드러운 스크롤 지원
- 폰트 크기 조절 (`A-`, `A`, `A+`) 및 다크/라이트 모드 지원

### 2. 🎯 다양한 응시 모드
- **1교시 실전 모의고사**: 필수 3과목 75문항 / 75분 제한시간
- **2교시 실전 모의고사**: 전공 4과목 100문항 / 100분 제한시간
- **실전 풀세트 모의고사**: 전체 7과목 175문항 / 175분 제한시간
- **과목별 집중 연습 모드**: 7개 과목 중 선택하여 문제 풀이 즉시 정답 및 해설 확인
- **오답노트 & 다시 풀기**: 지금까지 틀린 문제들만 모아서 즉시 재응시
- **북마크(★) 모음**: 중요 문항만 별표 체크하여 반복 학습

### 3. 📋 슬라이드 OMR 카드 (Drawer)
- 하단 OMR 버튼 터치 시 전체 문항 그리드 표시
- 미답안, 마킹 완료, 북마크 문항 색상 구분 및 원클릭 바로가기
- 실시간 타이머 및 남은 문항 수 안내

### 4. 📊 자동 채점 & 심층 성적표
- **공인 합격 기준 판정**: 전 과목 평균 60점 이상 & 매 과목 40점 이상 (과락 여부 실시간 진단)
- 과목별 점수, 정답률 바 차트, 과락 기준선(40점) / 합격 기준선(60점) 인디케이터
- 전체 문항 정오표(O/X) 및 **심층 해설 / 5개 보기별 개별 오답 반증 / 학술·법령 출처(DOI)** 제공
- **[틀린 문제 다시 풀기]** 원클릭 재응시 지원

### 5. 💾 100% 오프라인 & 로컬스토리지 지원
- 인터넷 연결 없이도 브라우저에서 독립 구동
- 시험 중 새로고침/앱 종료 시 직전 답안 자동 임시저장
- 최근 30회 응시 이력 및 누적 오답노트 영구 보관

## 🚀 GitHub 배포 가이드 (`https://github.com/kbjun22/exam`)

본 웹앱은 별도의 빌드 과정(npm, webpack 등)이 필요 없는 순수 정적 웹앱(Pure Static SPA)입니다.

### GitHub 저장소 업로드 방법:
```bash
# 1. exam 디렉터리로 이동 (또는 루트에서 exam 폴더를 커밋)
cd exam

# 2. git 초기화 및 원격 저장소 연결
git init
git add .
git commit -m "feat: 2026 청소년상담사 1급 실전 모의고사 모바일 CBT 웹앱 배포"
git branch -M main
git remote add origin https://github.com/kbjun22/exam.git
git push -u origin main
```

### GitHub Pages 무료 호스팅 설정:
1. GitHub 저장소 (`https://github.com/kbjun22/exam`)의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴의 **Pages**를 클릭합니다.
3. **Build and deployment** -> **Source**에서 **Deploy from a branch**를 선택합니다.
4. **Branch**를 `main` / `/(root)` 로 지정하고 **Save**를 클릭합니다.
5. 1~2분 후 `https://kbjun22.github.io/exam/` 주소로 전 세계 어디서든 모바일 스마트폰으로 접속하여 시험을 치를 수 있습니다!
